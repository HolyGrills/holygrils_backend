‎2. Expected Result — What should happen

‎5. MENU ITEM HP MULTIPLIER (1/2x, 2x) — Tests
‎
‎Test 5.1: Admin Sets HP Multiplier on Menu Item
‎
‎Step Action Expected Result
‎1 Admin edits menu item via PATCH /menu/items/{id} ✅ Item updated
‎2 Admin sets hp_multiplier = 2.0 ✅ Multiplier saved
‎3 Check database: menu_items ✅ hp_multiplier = 2.0
‎
‎Test 5.2: User Orders Item with 2x HP Multiplier
‎
‎Step Action Expected Result
‎1 User orders item with hp_multiplier = 2.0 ✅ Order placed
‎2 Order total = ₦1,000 ✅ HP calculation: ₦1,000 * 0.10 * 2.0 = 200 HP
‎3 Check HP balance ✅ 200 HP awarded
‎
‎Test 5.3: User Orders Item with 0.5x HP Multiplier (Half HP)
‎
‎Step Action Expected Result
‎1 User orders item with hp_multiplier = 0.5 ✅ Order placed
‎2 Order total = ₦1,000 ✅ HP calculation: ₦1,000 * 0.10 * 0.5 = 50 HP
‎3 Check HP balance ✅ 50 HP awarded
‎
‎Test 5.4: Multiplier Affects Tier Bonus Calculation
‎
‎Step Action Expected Result
‎1 User has tier with 1.15 multiplier ✅ Tier bonus applied
‎2 Item has hp_multiplier = 2.0 ✅ Combined multiplier: 2.0 * 1.15 = 2.3
‎3 Order total = ₦1,000 ✅ HP: ₦1,000 * 0.10 * 2.3 = 230 HP
‎
‎Test 5.5: Multiplier Does Not Affect Pending Unlock
‎
‎Step Action Expected Result
‎1 User orders item with hp_multiplier = 2.0 ✅ HP earned = 200 HP (ACTIVE)
‎2 Pending unlock rate = 30% ✅ Unlock: 200 * 0.30 = 60 HP (PENDING → ACTIVE)
‎3 Check HP balance ✅ 60 HP unlocked from pending
‎
‎Test 5.6: Admin Removes Multiplier (Set to 1.0)
‎
‎Step Action Expected Result
‎1 Admin sets hp_multiplier = 1.0 ✅ Multiplier reset to default
‎2 User orders item ✅ HP calculation normal (no multiplier)
